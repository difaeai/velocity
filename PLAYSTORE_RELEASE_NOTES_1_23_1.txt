(Build numbers are EAS's remote auto-increment; the build list is the truth.)

WHY 1.23.1. iOS 1.23.0 (build 26) is READY_FOR_SALE, read from the App Store
Connect API on 31 Oct before choosing — an approved version string closes its
train, so nothing more can go up as 1.23.0.

WHAT IT CARRIES. The screen states (PR #155): every error says what went wrong,
whose fault it is and how to fix it; offline and slow-network notices; permission
explanations with Open Settings; skeletons instead of spinners on 32 screens; typo
fixes in the city pickers; inline errors and a kept draft on the support form.
No native module was added.

OVER-THE-AIR UPDATES START WITH THIS BUILD. app.json now carries
runtimeVersion { policy: appVersion } and the EAS Update URL; eas.json's
production profile builds on channel "production". From 1.23.1 on, a JS-only
change ships with `eas update --channel production` from apps/mobile — no store
review. Anything that adds or changes NATIVE code still needs a version bump and
a store build (the runtime is the app version, so a 1.24.0 build never receives an
update made for 1.23.1).

APP STORE "WHAT'S NEW" (set on a NEW 1.23.1 version record)
-----------------------------------------------------------
A calmer, clearer Velocity.

Screens now show the shape of what's loading instead of a spinner. If you lose your connection, the app tells you, keeps what's on screen and says what still works; on a slow connection you see the real progress.

When something goes wrong, the message says what happened, whose side it was on and how to fix it. When the app needs your camera, location or microphone, it explains why and takes you to Settings.

City search fixes typos for you, and the support form points to the exact field that needs fixing — and keeps your message until it's sent.
